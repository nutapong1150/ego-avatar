# สูตรรูปแบบคลิปสั้น (format recipes)

ถอดจากการดูคลิปตัวอย่างจริงใน gallery ของ ii23 school (ii23-gallery.pages.dev, ดู 2026-10-04: คลิป 01 02 14 41 55 69 70 71 ทั้งหมดเป็น 9:16 1080×1920 30fps ยาว 21–29 วิ) · เก็บไว้แค่**โครงและกลไก**ที่เอาไปใช้ซ้ำได้ ไม่ได้ลอกเนื้อหา · คลิปเหล่านี้ใช้ฟุตเทจ stock เป็นพื้น + กราฟิกซ้อน → ทำด้วย HyperFrames/`video-use` (มีฟุตเทจ) หรือทาง C (ถ้าใช้รูปสินค้า/วาดเอง)

## ระบบร่วมที่ทุกคลิปมี (ใส่ทุกงาน)
```
 ┌──────────────────────────┐
 │ [ป้ายหัวค้าง] hook/หมวด     │ ← อยู่ตลอดคลิป คนเลื่อนมาเจอกลางคลิปยังรู้เรื่อง
 │  HUD: 1/3 · ฿ · เวลา      │ ← ตัวนับ/ราคาวิ่ง บอกว่าอยู่ตรงไหนของเรื่อง
 │                          │
 │      ฟุตเทจ/ภาพ เปลี่ยน     │ ← ตัดทุก 2–3 วิ ไม่มีภาพนิ่งเกิน 3 วิ
 │                          │
 │  ซับ 2 บรรทัด คำเด่นสีเน้น  │ ← ~65–75% ความสูง เหนือแถบ UI แพลตฟอร์ม
 │ [CTA ชี้ไปที่ตะกร้า] ↙      │ ← มุมล่างซ้าย = ตำแหน่งตะกร้า TikTok Shop
 └──────────────────────────┘
```
- **ป้ายหัวค้าง:** กล่องขาวตัวดำ หรือแถบหัวเรื่อง + ป้ายเล็ก ("รีวิวจริง · ใช้มา 2 อาทิตย์" · "ตอนที่ 1 · ฉบับเต็มใน 30 วินาที")
- **ซับ:** 1–2 บรรทัด ตัวขาวขอบดำ/เงา · **1–2 คำสำคัญเป็นสีเน้น** (เหลือง/แดง) · เปลี่ยนทุกประโยค
- **พื้นที่ปลอดภัย 9:16:** ห้ามวางของสำคัญที่ขอบขวา (ปุ่มไลก์/แชร์) และ ~12% ล่างสุด (ชื่อช่อง/แคปชัน)
- **ภาพไม่นิ่ง:** ซูมเข้าช้าๆ ตลอด (Ken Burns) แม้เป็นภาพนิ่ง

## สูตรตามงาน

| สูตร | โครง (วินาทีโดยประมาณ ของ 20–30 วิ) | กลไกเด่น |
|---|---|---|
| **ปักตะกร้า TikTok Shop / affiliate** | ป้ายหัว = คำสัญญาสินค้า ค้างตลอด · 0–3 ปัญหา ("ใครขี้เกียจล้าง…") · 3–14 ใช้งานทีละขั้น ภาพมือ/สินค้าจริง · 14–18 **เปิดราคา** · 18–21 CTA | ราคาเดิมขีดฆ่า → ราคาใหม่ตัวใหญ่สีแดง + ป้าย −66% + pill "ส่งฟรี" + ป้าย "โปรวันนี้เท่านั้น" · ปุ่มส้ม "กดตะกร้าเลย" + ลูกศรชี้มุมล่างซ้าย "ลิงก์สินค้าอยู่ในตะกร้า" |
| **รีวิวตรงๆ** | 0–3 คำถาม hook มีราคา ("X ฿2,900 คุ้มไหม?") · ข้อดี → ข้อเสีย → สรุป | **การ์ดสะสม** (เช็คเขียว/กากบาทแดง เพิ่มทีละบรรทัด) · สรุป = การ์ดราคา + คะแนน 8/10 ดาว · pill คิวเสียง ("ลองฟังเสียงพิมพ์") |
| **UGC (คนรีวิวหน้ากล้อง)** | ป้ายหัวเรียกกลุ่มเป้าหมาย ("ผู้ชายหน้ามันต้องดูคลิปนี้") · ปัญหา → เผยสินค้า → ใช้ → ผล "ผ่านไป 2 สัปดาห์" → CTA | ฟุตเทจคนจริง (ต้องเป็นคนที่ยินยอม · ห้ามหน้า AI ทำรีวิวปลอม) |
| **ไต่ระดับราคา** (฿500 → ฿5,000 → ฿50,000) | 0–2 **เปิดด้วยตัวแพงสุดก่อน** แล้วย้อนไปถูกสุด · ทีละระดับ · "?" ก่อนเฉลยระดับสุดท้าย · สรุปเรียงอันดับ | HUD ตัวนับ "ห้อง 1/3" + ราคามุมขวา · เช็คลิสต์ของที่ได้เพิ่ม · **CTA คอมเมนต์ "1, 2 หรือ 3"** (ปั่น engagement) |
| **VS เทียบสองทาง** (ทำเอง vs จ้าง) | จอแบ่งบน/ล่าง เล่นพร้อมกัน · "ขั้นที่ 1/5" | ตัวนับเวลา + เงินสะสมวิ่งทั้งสองฝั่ง · chip ค่าใช้จ่ายต่อขั้น · สรุป "ประหยัดกว่า ฿305 แต่ใช้เวลาเพิ่ม 60 นาที" · ปิดด้วยแบรนด์ |
| **สปอยหนัง / เล่าเรื่องเป็นตอน** | ป้ายหัว = ชื่อเรื่อง + "ตอนที่ 1" ค้าง · เกรดสีมืด · ซับคำเด่นสีแดง · จบด้วย "ตอนต่อไป…" | cliffhanger ดึงไปดูตอนถัดไป (ทำเป็นซีรีส์) |
| **ประวัติศาสตร์ / สารคดี** | ตัวเลขปี/วันที่ตัวใหญ่ · แผนที่เก่า + เส้นทางเดินทัพเป็นเส้นประลูกศรค่อยๆ วาด · ป้ายชื่อเมือง | โทนซีเปีย · ป้ายเครดิตภาพเล็กๆ ด้านบน ("ภาพ: … ค.ศ. 1904") · ภาพเก่าสาธารณสมบัติ |
| **ตัดแปะกระดาษ (collage)** อธิบายข่าว/การเงิน (เครื่องมือ: `M.torn` ขอบฉีก + `M.jitter` stop motion 12fps ใน motion-design-craft) | พื้นกระดาษคราฟต์ · สติกเกอร์ "ข้อ 1/2/3" · ภาพตัดขอบฉีก · ลูกศร/วงกลมสีแดง | การ์ดสูตร ("ราคาทองไทย ≈ ราคาโลก × ค่าเงินบาท") · คนตัดแปะชี้ตอนสรุป · ทำด้วยทาง C ได้ทั้งหมด (CSS clip-path ขอบฉีก + ภาพ) |

## จากบทความ (ยืนยันสิ่งที่เรามีแล้ว)
- โครงคลิปขาย 15 วิ: 0–3 ปัญหาตัวใหญ่ · 3–10 สินค้า + จุดเด่นทีละข้อ · 10–15 ชื่อสินค้า + "ลิงก์อยู่หน้าโปรไฟล์"
- กฎ: ภาพห้ามนิ่ง กล้องซูมเข้าตลอด · ของเลื่อนเข้าแล้วค่อยหยุดนุ่มๆ · เปลี่ยนฉากลื่น · ตัวหนังสือห้ามล้น/ทับ · **ภาพนิ่ง 4 ภาพให้ท่านดูก่อนเรนเดอร์** (ตรงกับ motion-design-craft)
- เตรียม `my-brand/brand.md` (ชื่อสินค้า ปัญหาลูกค้า จุดเด่น 3 ข้อ สี) + `product.png` ลบพื้นหลัง → ใช้เป็นรูปแบบไฟล์ input มาตรฐานของงานขายของ
